# Secure Systems Information Worksheets

This repository contains individual solutions to the practical worksheets completed during the previous semester for the **Secure Systems Information (SSI)** course. The material was developed for learning and consolidating the topics covered in the course.

The material covers operating-system security, cryptography, authentication, web security, software vulnerabilities, and injection attacks. It includes explanations, shell scripts, C programs, Python implementations, and Docker-based lab setups.

## Contents

- **S3** - Linux users, groups, file permissions, setuid, and access-control lists.
- **S4** - Capability leaking and privilege escalation through leaked file descriptors, including mitigations with `O_CLOEXEC`.
- **S5** - Classical cryptography: Caesar cipher, Vigenere cipher, one-time pad, weak pseudo-randomness, and key reuse attacks.
- **S6** - Modern cryptography: AES-CBC, AES-CTR, ChaCha20, nonce reuse, bit flipping, password-based encryption, salts, and nonces.
- **S7** - Message authentication: prefix-MAC length-extension attacks, AES-CTR with HMAC, and AES-GCM.
- **S8** - Diffie-Hellman key exchange, HKDF, AES-GCM, certificates, digital signatures, and the Station-to-Station protocol.
- **S10** - Cross-site scripting, Elgg security tokens, stored XSS, Content Security Policy, nonces, and a Docker-based web lab.
- **S11** - Memory-safety vulnerabilities in C, including stack buffer overflows and format-string vulnerabilities, compiler mitigations, exploitation, and remediation.
- **S12** - SQL injection and command injection, followed by query parameterization and safe file handling.
